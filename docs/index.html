PhoneKey23

A native Android WireGuard VPN client. No ads, no subscription, no account and no tracking.

Important: the website does not connect a VPN.

The browser page is for project information and downloads. A real VPN tunnel can be started only from the installed Android APK, using Android's VPN permission and a valid WireGuard server profile.

Get Android APK Source repository

What you need

  1. Install the Android APK from GitHub Releases.
  2. Obtain a valid WireGuard client profile from your own server or VPN provider.
  3. Import the .conf file or scan its QR code in PhoneKey23.
  4. Approve Android's VPN permission prompt and connect.

PhoneKey23 does not provide a VPN server. Without a working WireGuard endpoint and a valid peer configuration, the app cannot establish a real connection.

Compatibility

Android 8.0 (API 26) or newer. Package ID: com.phonekey.vpn.

Security note

Back up your WireGuard profile securely before reinstalling the app. The app encrypts profile data with a key held in Android Keystore; deleting app data or reinstalling can make old encrypted profile data unrecoverable.
