The key that joins you with your own.

A native WireGuard client for Android.

PhoneKey23 is free software for a WireGuard server you already run or trust. No ads, no subscription, no account, and no tracking. The private key stays on the phone.

This website does not connect a VPN.

It is a project and download page. Nothing here can change your IP address, route traffic, or start Android’s VPN service. A tunnel starts only in the installed app, after you import a real WireGuard profile and approve the system VPN prompt. PhoneKey23 does not ship a server.

What you need

The app is the client. The server is yours. Without a working WireGuard endpoint and a valid peer, PhoneKey23 has nothing to connect to.

  1. 01
    Install the Android APK. Release v1.0.2 attaches app-debug.apk, a debug-signed build for installation and testing. It is not a Play Store package. A signed PhoneKey23-release.apk is published only when the release signing secrets are configured.
  2. 02
    Bring a real WireGuard profile. Get a .conf from your own server or from a provider that gives you WireGuard, not from this project. Placeholder hosts such as example.com and documentation addresses are rejected.
  3. 03
    Import it on the phone. Use the file picker, scan the profile QR code, or type the keys into the form. Then pick that profile.
  4. 04
    Approve Android’s VPN prompt and connect. The app reports connected only after a WireGuard peer handshake. If none arrives within 25 seconds, it stays disconnected and tells you to check the endpoint, keys, UDP port, and server.

What the Android app does

These are the behaviors in the current Kotlin client. The in-app name is PhoneKey. The project and package are PhoneKey23 / com.phonekey.vpn.

  • 01

    WireGuard, then a handshake

    The tunnel is a foreground Android VPN service driven by WireGuard’s GoBackend. “Connected” waits for a peer handshake. Traffic totals and up/down rates show only after that.

  • 02

    Profiles you can actually manage

    Import a .conf, a QR code, or a typed form. Edit, select, and delete profiles. Show a QR, or export and import a JSON list. Both the QR and the JSON include private keys.

  • 03

    Keys sealed on the device

    Profile text is encrypted with AES-GCM. The key is created in Android Keystore and is not written into the profile file. Backup and device transfer of app data are disabled.

  • 04

    Connect from more than the button

    Use the home screen, the ongoing notification, or the Quick Settings tile. Optional auto-connect can run on launch, or after boot when VPN permission was already granted.

  • 05

    Split tunneling by app

    Choose installed apps or type package names. Selected apps can bypass the tunnel, or only the selected apps can use it. With the switch off, nothing is filtered.

  • 06

    A kill switch with a stated limit

    If the session drops, the app retries a few times. While its process is alive it can also hold an interface that forwards nothing. That block ends if the process dies. For a block that survives reboot or force-stop, set PhoneKey as Android Always-on VPN and turn on “Block connections without VPN”.

Protocol support

Older profile text for other protocols can be recognized so it can be refused. It cannot be selected, and the app will not report a false connection.

Only WireGuard has a working tunnel engine.
Protocol Status in the Android app
WireGuard Implemented. Requires your own working server and a valid profile. The config is parsed and handed to the WireGuard GoBackend.
Xray / V2Ray Not implemented. Import and connect are rejected. There is no Xray engine in this app.
SSTP Not implemented. Import and connect are rejected. There is no SSTP engine in this app.

Install, and keep your profiles

Android allows an update only when the new APK has the same package id and the same signing certificate.

  • v1.0.2 is debug-signed

    The file on that release is app-debug.apk. A later PhoneKey23-release.apk uses a different certificate unless you built both with the same keystore. Android will refuse that update. Uninstalling, or clearing app data, can make Keystore-encrypted profiles unrecoverable. Export a copy to a place you control first.

  • Permissions, and why they exist

    Internet and network state run the tunnel. The foreground-service permissions keep the VPN notification up. Notifications show status and connect or disconnect. Boot completion and a short wake lock are for optional auto-connect. The camera is requested only when you open the QR scanner. The VPN service itself cannot start until you accept Android’s consent dialog.

  • Build it yourself

    The Android project is in phonekey/. It uses JDK 17, Kotlin, and Jetpack Compose, with minSdk 26 and targetSdk 35. Open that directory in Android Studio, or run the Gradle tasks in the README. CI runs core tests, the web checks, Android unit tests, and emulator UI tests. A version tag publishes a signed release APK only after those jobs pass and the signing secrets are present.

  • Source archive

    v1.0.2 also attaches phonekey-source.zip. The full repository, including this page, is Tajoor621/PhoneKey23. The license is Apache-2.0. The WireGuard tunnel library is Apache-2.0 as well.

What this project will not do

PhoneKey23 is a client. The limits below are intentional.

  • No server, account, or subscription

    There is no hosted endpoint, no login, and no plan to buy. If you do not have a WireGuard server, the app cannot invent one.

  • No ads and no analytics

    The Android app does not include an ad SDK or a telemetry client. This page loads no third-party scripts, fonts, or trackers. The checklist never leaves the browser.

  • No other VPN protocols

    Xray, V2Ray, and SSTP are refused. Do not treat a rejected profile as a connection.

  • The browser companion is not a VPN

    The repository also contains a browser profile screen for trying the import UI. Any speeds shown there are simulated. That screen cannot create an Android VpnService or route device traffic.

Questions

Does opening this site protect my traffic?

No. The site cannot start a VPN. Install the Android app and connect from there, with your own WireGuard server.

Where do my keys go?

On the phone, sealed with Android Keystore. Export and QR sharing copy the private key on purpose, so treat those files like the tunnel itself. Reinstalling the app can make the sealed copy unreadable. Keep your own backup.

Is the in-app kill switch a system block?

No. It retries a dropped WireGuard session and can hold a non-forwarding interface only while the app process is alive. Android’s Always-on VPN setting, with “Block connections without VPN”, is the persistent control.

Which Android versions are supported?

Android 8.0, API 26, through a target of API 35. The version name of the current client is 1.0.2. The package id is com.phonekey.vpn.
