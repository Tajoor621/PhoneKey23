PhoneKey

A WireGuard client for Android. No ads, no subscription, and no tracking. You bring your own server. PhoneKey does not ship one.

Download the Android project Latest release

What works

ProtocolStatus
WireGuardWorking, via the official tunnel library.
Xray / V2RayNot implemented. The app refuses these configs.
SSTPNot implemented. The app refuses these configs.

Open it

Unzip the project and open the phonekey folder in Android Studio Ladybug or newer, with JDK 17. minSdk is 26. The debug APK is attached to GitHub Releases starting with 1.0.2.

Addresses such as 203.0.113.1 are documentation space. PhoneKey will not save or connect them.

Kill switch

The in-app switch reconnects a few times and can hold a tunnel that drops traffic while the app process is alive. For a block that survives a reboot, set PhoneKey as Always-on VPN and turn on “Block connections without VPN” in system VPN settings. The app has a button that opens that screen.

Policy

No ads. No billing. No analytics. No accounts. Camera access is asked only when you scan a QR code. WireGuard configs are encrypted with the Android Keystore before they are written to disk.
